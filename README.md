# Zen Time · 一段飞往静默的旅程

沉浸式冥想应用。选择一个远方场景，跟随盒式呼吸法 4-4-4-4 节奏，在引导文案中完成一次内心的远行。

**https://e61d0597f98949579c771c61bddd0816.app.workbuddy.link**

> 建议佩戴耳机、使用手机端打开以获得最佳体验。首次加载约需 1-3 分钟（预加载全部音视频素材）。

## 四个场景

| 场景 | 地点 | 意象 | 时间 |
|------|------|------|------|
| 极光 | 特罗姆瑟 (69°N) | 极夜 · 极光 · 幽蓝 | 23:47 |
| 海洋 | 冲绳·座間味島 | 潮声 · 海风 · 远帆 | 17:32 |
| 森林 | 屋久島 | 苔藓 · 晨雾 · 杉木 | 06:18 |
| 沙漠 | 纳米布沙漠 | 古沙 · 长风 · 旷野 | 05:44 |

每个场景配有专属环境音（真实录制的 MP3）和全屏循环视频背景。

## 核心功能

- **盒式呼吸法 4-4-4-4**：吸气 4s → 屏息 4s → 呼气 4s → 屏息 4s，16 秒一个循环
- **呼吸引导圆**：CSS 方波动画驱动三环缩放，中心实时显示动作字（吸/屏/呼）+ 倒计时
- **场景化引导文案**：4 场景 × 3 时长（1/3/5 分钟）= 12 组专属引导词，每行文案与呼吸阶段严格对齐
- **全量预加载**：6 个视频 + 4 个音频在入场黑屏期间并行加载，进度轴实时反馈
- **飞行过渡**：入口屏 → 冥想屏之间用全屏舷窗视频做 crossfade 过渡
- **Canvas 兜底**：视频加载失败时自动降级为 Canvas 动态渐变背景

## 技术架构

```
index.html          # 三屏结构：入场黑屏 / 入口屏 / 冥想屏 / 结束屏
├── css/
│   └── style.css   # 全部样式：黑白灰衬线极简 + CSS 方波呼吸动画

│   ├── data.js     # 场景数据 + 12 组引导文案（按呼吸相位排列）
│   ├── app.js      # 应用控制：预加载 / 场景切换 / 过渡状态机
│   ├── session.js  # 冥想会话：呼吸时钟 / 文案调度 / 计时进度
│   ├── audio.js    # Web Audio API：环境音播放 / 风声合成 / 淡入淡出
│   └── visuals.js  # Canvas 兜底：渐变动画 + 噪点纹理

    └── audio/      # 4 个 MP3 环境音
```

## 技术亮点

### 视频元素池模式（无缝场景切换）

摒弃传统的「单个 video 元素 + 切换 src + load()」方案，改为 4 个独立 `.scene-video` 元素各持 src，预加载后直接 `play()`，切换时只切 CSS class——**零缓冲、零卡顿**。

### Web Audio API 实时合成

飞行界面的高空风声不是音频文件，而是用 Web Audio API 实时合成的：棕噪声 → 低通滤波（550Hz）→ 慢速 LFO 调制（0.08Hz）。场景环境音则用 `fetch()` 预加载为 ArrayBuffer，运行时 `decodeAudioData` 解码，实现精确的音量淡入淡出控制。

### 呼吸时钟与文案时钟同步

呼吸圆 CSS 动画为 16s 方波四相位，JS 呼吸时钟每 500ms 轮询计算当前阶段。文案调度器固定 4 秒切换一行，与呼吸阶段严格对齐——文案说"吸气"时，呼吸圆正在放大；文案说"屏住"时，圆完全静止。

### Canvas 截帧生成缩略图

场景选择器的圆圈缩略图不是额外图片资源，而是预加载阶段从视频首帧 `drawImage` → `toDataURL` 动态截取的，零额外网络请求。

### 场景专属样式

通过 `data-scene` 属性为不同场景定制样式。例如森林场景底部水面偏白，自动叠加暗色渐变遮罩 + 文字阴影增强可读性。

## 如何运行

```bash
# 克隆仓库
git clone https://github.com/jasonmenggao/zen-time.git
cd zen-time

# 下载媒体文件（视频 + 音频，约 120MB）
# 从 Release 页面下载 assets.zip，解压到 assets/ 目录
# 下载地址：https://github.com/jasonmenggao/zen-time/releases

# 任意静态服务器即可，例如 Python
python -m http.server 8080

# 浏览器打开
# http://localhost:8080
```

> **注意**：媒体文件（视频/音频）因体积较大未纳入 git 跟踪，请从 [Releases](https://github.com/jasonmenggao/zen-time/releases) 页面下载并解压到 `assets/` 目录。
